## 1. Цель работы
Экспериментально исследовать временную сложность алгоритмов, сравнить
фактическое время с теоретической оценкой T(n) = C·f(n), построить аппроксимацию
и оценить её качество (MSE), освоить методику корректного бенчмаркинга.

## 2. Постановка задачи
Приложение (C#, WPF) с выбором алгоритма, конфигурацией (Nmax, step, запуски,
seed, лимит времени), БД результатов с кэшем (Use cache / Force recalculation),
графиками, аппроксимацией C·f(n) и MSE; отдельный операционный бенчмарк
возведения в степень (n = 1..1000, измеряется количество операций).

## 3. Теоретические основы
- Сложности: O(1), O(log n), O(n), O(n log n), O(n²), O(n³).
- Теоретическое время: T(n) = Σᵢ countᵢ(n) · costᵢ; константы costᵢ определяются
  калибровкой (Documentation/BenchmarkMethodology.md).
- Аппроксимация: Tapprox(n) = C·f(n), C = Σ f·t / Σ f² (МНК через начало координат).
- MSE = (1/k) · Σ (T_эмп(nᵢ) − Tapprox(nᵢ))².

## 4. Описание алгоритмов
По каждому алгоритму: описание, применение, Best/Average/Worst сложность,
число элементарных операций — Documentation/Algorithms.md.
Список: O(1); сумма O(n); произведение O(n) (mod-арифметика); многочлен наивно
O(n²); Горнер O(n); Bubble Sort O(n²); Quick Sort O(n log n) average / O(n²) worst;
TimSort O(n log n) (собственная реализация); умножение матриц O(n³);
индивидуальный: быстрое возведение в степень O(log n); три варианта возведения
в степень для операционного бенчмарка.
